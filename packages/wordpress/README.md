# Reedach для WordPress

Плагин с подсказками по стилю русского текста в редакторе блоков: канцелярит, штампы, вода,
оценочные слова, тяжёлый синтаксис, частые ошибки, просторечия, типографика. Проверка идёт в
браузере автора на ядре [`reedach`](../core), текст никуда не отправляется. Сервер не нужен,
поэтому плагин работает на любом хостинге. Орфографии здесь нет: для неё нужен
[сервер Reedach](../server).

- Панель Reedach в редакторе: список подсказок, нажатие выделяет фрагмент в тексте.
- Подсветка прямо в блоках (Chrome и Edge 105+, Safari 17.2+, Firefox 140+).
- Настройки → Reedach: какие виды подсказок показывать авторам.
- Интерфейс на русском и английском. WordPress 6.5+, PHP 7.4+.

## Установка

Скачайте `reedach-wordpress-X.Y.Z.zip` из [релизов](https://github.com/dimafaller-en/reedach/releases)
и загрузите в «Плагины → Добавить новый → Загрузить плагин».

## Разработка

Папка `reedach/` и есть плагин. Код редактора лежит в `src/editor.js`, сборка кладёт его вместе
с ядром в `reedach/build/editor.js` и список категорий правил в `reedach/includes/categories.php`:

```bash
npm run build -w reedach-wordpress
```

Сборка закоммичена. Версия плагина в `reedach.php` и `readme.txt` должна совпадать с
`package.json`, иначе сборка остановится. Архив для релиза собирает GitHub по тегу `vX.Y.Z`.

История версий всех пакетов — в [CHANGELOG.md](https://github.com/dimafaller-en/reedach/blob/main/CHANGELOG.md).
