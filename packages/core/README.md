# reedach

Ядро проекта Reedach: лёгкая проверка русского текста на канцелярит, штампы, воду,
неконкретные и оценочные слова, длинные предложения и абзацы. Без зависимостей,
работает в браузере и в Node. Текст никуда не отправляется.

Это простые подсказки по словарю и правилам: проверка иногда ошибается
и не заменяет редактора.

```bash
npm i reedach
```

```js
import {checkStyle, sourceBlocks, mergeIssues} from 'reedach';

const markdown = 'В настоящее время мы осуществляем доставку хлеба.';
const blocks = sourceBlocks(markdown);
const issues = mergeIssues(blocks, {local: checkStyle(blocks)});
// [{start, end, id, category, label, message, fix, replace?, edit?}, …] — start и end указывают в исходный текст,
// replace — варианты замены, если они есть
```

Готовые правки. `replace` — варианты для фрагмента `start`…`end`; кнопка ставит вариант
на место фрагмента, с заглавной буквы, если фрагмент начинался с заглавной. У замечаний, где
в правиле нет замены, ядро даёт её само, если её можно сделать механически: «счет на оплату» →
`["счет"]`, «согласно договора» → `["согласно договору"]`, «Мы  и» → `[" "]`.

`edit` — одна готовая правка, когда она не укладывается в `replace`: убрать фрагмент или
поменять кусок шире фрагмента замечания (знак после него, «, что» за оборотом):

```js
// «Не секрет, что цены растут.» → «Цены растут.»
{start: 0, end: 9, id: 'intro-obviousness', …, edit: {start: 0, end: 16, text: 'Ц', remove: true}}
// «Мы купили дом. Который стоит у реки.» → «Мы купили дом, который стоит у реки.»
{start: 15, end: 22, id: 'syntax-fragment-start', …, edit: {start: 13, end: 22, text: ', который'}}
```

Применить правку — заменить в исходном тексте `edit.start`…`edit.end` (те же координаты, что
у `start` и `end`) на `edit.text`. Заглавная буква, запятые и пробелы уже учтены.
`remove: true` — это «Убрать»: фрагмент уходит вместе с запятыми и пробелами, которые остались
бы лишними, а если он начинал предложение, следующее слово получает заглавную (тогда `text` —
эта буква). Убрать можно только там, где без фрагмента фраза остаётся грамотной: вводное между
запятыми, «Не секрет, что» с его «, что», целое предложение «Спасибо за внимание!», определение
перед словом («Успешный проект» → «Проект», но не «Проект был успешным»). В остальных случаях
замечание остаётся советом. Внутри правки нет разметки Markdown, иначе правки нет.
У одного замечания бывает или `replace`, или `edit`.

Без Markdown: `checkStyle([{text: '…', kind: 'p'}])`, где `kind` — `p` (абзац), `li` (пункт
списка) или `h` (заголовок). Настройки длины: `checkStyle(blocks, {maxSentenceWords: 25,
maxParagraphWords: 120})`.
