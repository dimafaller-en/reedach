# История версий

Все пакеты Reedach выходят с одним номером версии: `reedach`, `reedach-widget`,
`reedach-server`, Docker-образ и плагин для WordPress.

## 0.4.0 — 24 октября 2026

- **«Убрать» одним нажатием.** Если без найденного оборота фраза остаётся грамотной, у подсказки
  есть кнопка «Убрать»: вводное слово между запятыми, «Не секрет, что …», предложение-формула
  «Спасибо за внимание!», лишнее определение перед словом. Вместе с оборотом уходят лишние
  запятые и пробелы, а следующее слово получает заглавную, если нужно: «Не секрет, что цены
  растут» → «Цены растут». Сразу после «не» и поперёк разметки кнопки нет, там остаётся совет.
- **Правки шире подсказки.** Кнопка «Принять «…»» меняет кусок рядом с найденным: «Мы купили
  дом. Который стоит у реки» → «Мы купили дом, который стоит у реки», лишний пробел перед
  знаком препинания уходит вместе с ним.
- **Больше готовых замен.** Плеоназмы («счет на оплату» → «счет», «свободная вакансия» →
  «вакансия»), падеж после «согласно» («согласно договора» → «согласно
  договору»), повтор слова («что что»), типографика: двойной пробел, пробел перед знаком,
  кавычки, тире. Любую правку отменяет Ctrl+Z.
- **С сервером Reedach** вариант встаёт в форму найденного оборота: «оказываем содействие» →
  «помогаем», «производим оплату» → «оплачиваем», «скриншоты» → «снимки экрана».
- Кнопки работают в виджете и в боковой панели плагина для WordPress.
- **Для разработчиков:** в ответе у подсказки новое поле `edit` `{start, end, text, remove?}` —
  готовая правка; как её применить, написано в README пакета `reedach`. Поле `replace` теперь
  приходит и у правил без своей замены, если её можно сделать механически.

## 0.3.3 — 16 октября 2026

- **Новые частые ошибки.** «Что бы» вместо союза «чтобы» («для того, что бы мы творили»,
  «что бы рассказать»), но не в «что бы ни случилось» и «не знаю, что бы почитать». «А так же»
  вместо «а также». «По настоящему», «по моему» вместо «по-настоящему», «по-моему», но не
  в «по новому адресу». У всех трёх правил есть исправление одним нажатием.
- **С сервером Reedach ещё три проверки:** «не» с прилагательным без противопоставления
  («не сложные сайты → несложные»), падеж после глаголов вроде «заниматься» («занимался
  настройка → настройкой») и опечатка «пой» вместо «мой» перед существительным («изменило пой
  подход»).

## 0.3.2 — 13 октября 2026

- **Плагин для WordPress.** Русский перевод интерфейса больше не лежит внутри плагина: так
  просит каталог WordPress.org, переводы там приходят с translate.wordpress.org. Пока русский
  перевод не загружен туда, интерфейс плагина на английском, подсказки по тексту по-прежнему
  на русском.

## 0.3.1 — 12 октября 2026

- **Плагин для WordPress.** Русский перевод интерфейса подключается без устаревшей функции
  `load_plugin_textdomain`, на которую ругалась проверка WordPress.org. Если для плагина есть
  перевод с translate.wordpress.org, используется он, иначе — встроенный.

## 0.3.0 — 12 октября 2026

- **Замена одним нажатием.** У многих подсказок есть готовый вариант: нажмите на него, и
  слово заменится в тексте. Без нажатия текст не меняется, замену отменяет Ctrl+Z. С сервером
  Reedach вариант встаёт в форме найденного слова: «релевантных → подходящих», «минимизировали →
  сократили». Без сервера, в том числе в плагине WordPress, кнопка с синонимом появляется,
  только когда найденное слово уже в начальной форме («релевантный», «дедлайн»), иначе остаётся
  совет. Точные исправления («вообщем → в общем», тире, «м²») работают везде.
- **Свои замены у каждого слова** в канцелярите, штампах, заимствованиях, жаргоне, частых
  ошибках и просторечиях. Где одним словом не заменить («в рамках проекта»), остаётся совет.
- **Паронимы:** «одел пальто → надел», «предвыборная компания → кампания», «представить доступ →
  предоставить». Подсказка срабатывает только рядом со словом, при котором ошибка однозначна:
  «одела ребёнка» не отмечается.
- **Больше слов:** около 120 англицизмов и жаргонных слов с русскими заменами («дедлайн → срок»,
  «фидбек → отзыв», «юзать → использовать»), 50 плеоназмов («памятный сувенир», «в конечном
  итоге»), 60 канцелярских оборотов («в случае если → если», «на постоянной основе → постоянно»).
- **Типографика:** дефис в диапазонах («10:00-18:00», «пн-пт», «8-12 мм»), три точки вместо
  многоточия, тире без пробела с одной стороны, сокращения без пробела («г.Москва», «т.е.»),
  «м2», «25-ый», «№5», «(c)». Исправление тоже вставляется нажатием.

## 0.2.0 — 12 октября 2026

- **Плагин для WordPress.** Подсказки по стилю в редакторе блоков: панель со списком
  замечаний, подсветка в тексте, нажатие на подсказку выделяет фрагмент. Работает без сервера,
  на любом хостинге. В «Настройках → Reedach» можно выключить ненужные виды подсказок.
  Архив плагина приложен к релизу на GitHub.
- **Свои замены для иностранных слов.** У каждого слова в правиле про латинизмы свой вариант:
  «релевантный → подходящий, нужный, уместный», «минимизация → сокращение, уменьшение».
- **Безопасность.** Специально подобранный текст больше не замедляет проверку: исправлены
  медленные регулярные выражения в проверке стиля, разборе Markdown и поиске адресов почты.
  Сервер проверяет текст в отдельном потоке и всегда отвечает на другие запросы.
- **Сервер.** Новая настройка `REEDACH_TIMEOUT` (20 секунд): проверка дольше
  останавливается с ответом 503. `REEDACH_MAX_BYTES` по умолчанию 200 000 вместо 1 000 000.
  JSON с глубокой вложенностью отклоняется с ответом 422.
- **Выпуски.** Публикация ждёт подтверждения владельца, шаги сборки закреплены
  по точным версиям.

## 0.1.2 — 12 октября 2026

- **Частые ошибки:** «вообщем», «по приезду», «согласно договора», «оплатить за»,
  «обоих сторон».
- **Просторечия** и повтор слова подряд.
- **Типографика:** лишние и недостающие пробелы, прямые кавычки, непарные скобки, дефис
  вместо тире, повтор знаков, слипшиеся инициалы, латиница внутри русского слова.
- В Markdown пробелы на месте кода, картинок и переносов строк больше не считаются
  опечатками. Ссылки со скобками в адресе разбираются целиком.

## 0.1.1 — 12 октября 2026

- Документация: логотип, скриншоты, подробнее про ключи сервера и орфографию на hunspell.
  Код не менялся.

## 0.1.0 — 12 октября 2026

- Первая публикация: ядро `reedach` со словарём правил, виджет `reedach-widget`
  для любого поля ввода, сервер `reedach-server` с орфографией, морфологией и HTTP API,
  Docker-образ `ghcr.io/dimafaller-en/reedach` для amd64 и arm64.
